# Hypo Loop

> 가설을 등록하면 AI 에이전트가 알아서 ML 실험을 설계·실행하고, 결과를 보고서로 돌려주는 **Auto Research Agent** 플랫폼

사용자가 검증하고 싶은 "가설"을 입력하면, 에이전트가 실험을 설계하고(피처·하이퍼파라미터·모델·산식), 학습 코드를 작성해 실행한 뒤, 점수와 분석을 모아 보고서로 보여줍니다. 사람이 반복적으로 돌리던 실험 루프를 자동화하는 것이 목표입니다.

---

## ✨ 주요 기능

- **가설 등록**: 사용자가 가설을 등록하면 프로젝트별로 관리
- **자동 실험 설계**: 에이전트가 피처/하이퍼파라미터/모델/산식을 구성
- **자동 학습 실행**: 에이전트가 트레인 코드를 작성하고 병렬로 실험 실행
- **실시간 상태 추적**: 실험 상태와 점수를 파일 기반으로 추적
- **결과 보고서**: 가설별 최고점, 실험별 점수 추이 그래프, 분석 텍스트 제공

## 🏗️ 아키텍처

```
┌─────────────┐      ┌─────────────┐      ┌──────────────────┐
│   프론트     │ ───▶ │   백엔드     │ ───▶ │  AI팀 (에이전트)  │
│ (UI/화면)    │      │ (FastAPI)    │      │  (LangGraph)      │
└─────────────┘      └─────────────┘      └──────────────────┘
                            │                       │
                            ▼                       ▼
                     ┌──────────────────────────────────┐
                     │  데이터 계층 (SQLite + YML 파일)   │
                     └──────────────────────────────────┘
```

### 데이터 계층

```
u_id (사용자)
└── project_id (프로젝트)
    ├── project.db          # 프로젝트별 로컬 SQLite
    └── 가설_id (가설)
        ├── u_id_가설_id.yml  # 가설 메타 (백엔드 생성)
        └── exp_id (실험)
            ├── exp_id.yml     # 실험 설계 (AI팀 생성)
            ├── status.yml     # 실험 상태/점수 (파일로 관리)
            └── 학습용 기능코드  # AI팀 생성
```

식별자 계층: `u_id → project_id → 가설_id → exp_id`

## 🚀 시작하기

> ⚠️ 아래는 초안입니다. 실제 실행 방법은 각 영역 구현 후 업데이트하세요.

### 사전 요구사항
- Python 3.11+

### 백엔드 실행 (예시)

```bash
# 저장소 클론
git clone https://github.com/28-hypoloop/hypoloop.git
cd hypoloop

# 백엔드 의존성 설치
cd backend
pip install -r requirements.txt

# 서버 실행
uvicorn app.main:app --reload
```

데이터 저장 경로 루트는 환경변수로 받을 예정입니다 (기본값 `data/projects/`).
_(경로 설정 방식은 팀 확정 후 업데이트)_
